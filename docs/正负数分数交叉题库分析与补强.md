# 正负数 / 分数题库分析与补强方案

2026-10-17 与用户确认定稿，当日双端实施完毕（iOS build 11）。
起因：女儿实测最突出薄弱点是**正负数加减，尤其是分数的正负数加减**。

## 一、现状原子能力拆解

### 分数线（五年级，全正数世界）

| 技能 | 原子能力 | 关键限制 |
|---|---|---|
| 分数的意义与改写 | 形态转换 | 全正 |
| 约分 / 通分 | 等值变形地基 | 全正 |
| 分数的大小比较 | 正数序关系 | 全正 |
| 分数加减法 | 同分母→异分母运算 | **减法重抽保证结果为正（P2 不出负数）** |
| 分数乘除 / 小数混合 | 运算扩展 | 全正 |

### 负号线（六年级 1.1~1.2，无分数）

| 技能 | 原子能力 | 数值范围 |
|---|---|---|
| 相反数与绝对值（B2） | 符号概念 | 整数 ±20 / 一位小数 ±9.9 |
| 正负数比大小（B2） | 负数序关系 | 同形态整数/一位小数 |
| 符号快闪（C3） | 不计算判正负 | 整数/一位小数 |
| 正负数加减 | 先定符号再算绝对值 | 整数/一位小数 |

### 断层

**分数线与负号线从未交叉**：五年级分数题一律全正（减法故意回避负结果），六年级负数题一律不出分数。
女儿做分数正负加减时，需要同时调用"通分/约分 + 符号规则 + 负数序关系"三条从未一起用过的链路——
这正是上海六年级（沪教版五四制）1.2 节的核心考点，也是校内考试丢分重灾区。

## 二、补强设计（4 个新技能）

判符号题型（三选一）键盘无法输入，独立成 supportsReview:false 技能，这是比初稿多一个技能的原因。

| 技能 | id | 挂载 | 限时 | 配比 |
|---|---|---|---|---|
| 负分数比大小 | g6-signed-frac-cmp | 六 1.1 | 5s | 负vs负 40%（同分子/同分母各半）/ 负分数vs负小数 25% / 正vs负 20% / 等值变形（-1/2 vs -0.5）15% |
| 分数符号快闪 | g6-signed-frac-flash | 六 1.2 | 4s | 相反数得 0 12%；其余两半：同分母带符号相加判号 50%、异分母正数相减判号 50% |
| 分数正负加减·基础 | g6-signed-frac-basic | 六 1.2 | 10s | 同分母带符号 45% / 倍数分母 30% / 不够减专项（结果为负）25% |
| 分数正负混合·进阶 | g6-signed-frac-adv | 六 1.2 | 14s | 互质分母严格异号相加 40% / 减负数（正−负、负−正各半）30% / 小数分数混合带符号 20% / 三项代数和 10%（分母组合 [2,3,4][2,3,6][3,4,6][2,4,8]） |

能力链设计意图：

1. **先比大小再运算**（1.1 挂比大小）：负数序关系是判符号的地基——判符号本质就是"比绝对值大小"。
2. **判符号先于计算**（快闪 4s）：不计算只判方向，把"先定符号"练成条件反射，再进计算题。
3. **基础→进阶**：基础同分母/倍数分母把通分负担降到最低、专注符号；进阶才上互质分母与混合形态。
4. **不够减专项**：小学从未见过"小数减大数"，这是有理数减法的第一道坎，单独 25% 强化。
5. **减负数专项**：正−负、负−正各半，口诀"减去负数 = 加正数"。

## 三、技术要点

- 负分数统一用 `frac('-n','d')`（负号在分子里）表示；渲染层（web MathView.tsx / iOS MathExprView.swift）
  把负号前置到分数线左边并标红，运算式中负分数项自动加括号（(-1/2) + 1/3）。
- 答案不产出带分数（hideMixedKey），假分数直接作为答案（acceptImproper）。
- 陷阱复用现有助手（pushTrap/fillTraps 对负分子天然可用）；新增 sAnsExpr（保符号约分）与
  sFormTraps（gcd 对负 N 失效，用绝对值判断）。
- 需要两个不同分子的同分母分支使用专用分母表 SIGNED_PAIR_DENOMS = [3,4,5,6,8]
  （d=2 最简分子只有 1 个，抽不出两个，会导致空候选 NaN——开发中实测踩到并修复）。
- id 统一 g6-signed-frac- 前缀，避开 validate.ts 中 g6-frac- 前缀的"题面必须是运算式"校验
  （比大小/判符号题不是运算式）。
