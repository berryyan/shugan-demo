# 数感星球 · 原子能力拆解与开发排期

> 原则：**不做教材辅助题库，而是把课标要求拆解成最小基本能力（原子能力），每个原子能力做成有趣的数感训练**。运算题只是原子能力的组合；孩子做错一道组合题，真正的短板永远落在某个原子上——我们的 trap 误区标签系统正是为这个归因设计的。
>
> 依据：《义务教育数学课程标准（2022 年版）》第三学段（分数小数四则、转化、数感）与第四学段（有理数运算，上海五四制六年级已涉及）；沪教版五四制（2024 版）六年级上册第 1 章「有理数」。

## 一、原子能力地图

```
数感与运算能力
├─ A. 数的表征转换（同一个数，多种样子，秒切）
│   ├─ A1 小数 ⇄ 分数锚点互化        ✅ 已上线
│   ├─ A2 假分数 ⇄ 带分数改写         ← 7/6 = 1⅙
│   ├─ A3 约分（等值变换感）          ← 25/75 = 1/3
│   └─ A4 百分数互化                  ⏸ 六下内容，暂缓
├─ B. 数的关系感（不计算就知道大概）
│   ├─ B1 分数/小数大小比较           ← ½ 和 ⅓ 谁大，0.6 和 ⅝ 谁大
│   ├─ B2 正负数意义与数轴            ← 相反数、绝对值、比大小
│   └─ B3 估算与结果合理性            ← 49×51 ≈ ? 选最接近
├─ C. 运算构件（所有速算题的原子步骤）
│   ├─ C1 整数心算                    ← 20 以内加减、乘法口诀、凑十
│   ├─ C2 通分（最小公倍数）          ← 异分母加减的地基
│   ├─ C3 符号规则                    ← 同号得正、减负数=加正数
│   ├─ C4 倒数                        ← 除法变乘法的开关
│   └─ C5 运算顺序与运算律            ← 先乘除后加减、分配律巧算
└─ D. 执行功能（小游戏厅已覆盖）      ✅ 专注/记忆/反应
```

**关键认知**：一道"¾ ÷ 0.25"的错题，根源可能是 A1（0.25 没认出是 ¼）、C4（忘倒过来）或 C1（3×4 算错）。只刷组合题无法定位短板；把原子拆出来单独练，组合题的正确率和速度会自然提升——这就是"数感培养"和"刷题软件"的本质区别。

## 二、每个原子能力的训练设计（玩法而非刷题）

| 原子 | 玩法 | 课标/教材对应 | 趣味性设计 |
|------|------|--------------|-----------|
| A1 小数⇄分数 | ✅ 快问快答（已上线） | 三学段"会进行小数分数转化" | 限时 + 误区干扰 + 连对加成 |
| A2 分数改写 | 快问快答：假分数⇄带分数互化 | 分数意义与性质 | 7/6 的"余数归位"直觉 |
| A3 约分 | 快问快答：给分数选最简形式 | 三学段"感悟计数单位" | "还能再约吗"陷阱项（5/15 没约干净） |
| B1 大小比较 | 快问快答：谁大/谁小/相等 | 三学段"比较两个分数的大小" | 纯直觉题，最适合限时秒杀 |
| B2 正负数与数轴 | 快问快答：气温/海拔情境比大小、求相反数绝对值 | 教材 1.1 节 | 生活情境代入 |
| B3 估算 | 快问快答：选最接近的估算结果 | 三学段"会选择合适方法估算" | 选项间距大，凭数感不靠算 |
| C1 整数心算 | 快问快答：两位数加减/表内乘除秒杀 | 运算一致性 | 节拍器式节奏，最短限时（5 秒） |
| C2 通分 | 快问快答：选公分母/最小公倍数 | 分数加减法算理 | 为 P2 异分母加减打底 |
| C3 符号规则 | 快问快答：只判断结果正负（不计算） | 教材 1.2/1.3 节 | "符号快闪"——先练符号直觉再练计算 |
| C4 倒数 | 快问快答：秒答倒数 | 教材 1.3 节 | 分数↔小数双形式混出 |
| C5 运算律巧算 | 快问快答：凑整（98+27）、分配律（25×36） | "运用运算律简化运算" | 选"最聪明的算法"而非答案 |
| 组合题 | 正负数加减、分数四则、混合运算（两项 90% + 三项 10%） | 教材 1.2/1.3/1.5 节 | 这是原子练熟后的"检验场" |

## 三、开发排期（按依赖关系，每期都是可玩的完整闭环）

> 排期原则：**表征先于运算，单项先于组合，直觉先于步骤，正确率先于速度**。

### P0 · 已完成 ✅
小数⇄分数转换（A1）+ 快问快答引擎 + 积分钱包 + 游戏厅（数字闪现/极速点击）+ 排行榜

### P1 · 数感地基（无负数、无多步，纯直觉）
- A2 分数改写（假分数⇄带分数）
- A3 约分训练
- B1 分数/小数大小比较

*为什么先做这三个：它们是分数运算的"零步骤"直觉，不受符号和步骤干扰，立刻就能让女儿玩起来并见效。*

### P2 · 分数运算单项（你点名的核心）
- C1 整数心算快闪（免费练习，作为热身）
- C2 通分（内嵌于异分母加减的引导中）
- 分数加法、分数减法（同分母 50% + 异分母 50%）
- 分数乘法、分数除法（内嵌 C4 倒数）

### P3 · 有理数完整化（对齐六上教学进度）
- C3 符号快闪 → 正负数加减速算（两项 90% + 三项 10%）
- 分数+小数混合运算（两项 90% + 三项 10%）
- B2 正负数与数轴情境题
- C5 运算律巧算

### P4 · 综合与个性化（机制层）
- 混合闯关（跨题库随机）
- 错题本 + 误区归因报告（告诉家长"短板在哪个原子能力"）
- 每日挑战（同种子同题，公平 PK）
- 难度自适应（连对则数值范围自动升级）

### 暂缓
- A4 百分数互化：六下第 5 章内容，等孩子学到再开
- 乘方速记（11²~20²）：教材 1.4 节，可插入 P3 末尾

## 四、本期（P1）开发明细

| Skill | 题面示例 | 答案形式 | 干扰项误区 |
|-------|---------|---------|-----------|
| 分数改写 | 7/6 → ? | 带分数 | 商错（2⅙）、余数错位（1⅐）、颠倒（6/7） |
| 分数改写（反向） | 2⅓ → ? | 假分数 | 忘加整数（2/3）、乘错（5/3） |
| 约分 | 25/75 → ? | 最简分数 | 没约干净（5/15）、减同数（24/74 类） |
| 大小比较 | ⅝ vs 0.6 | 选大者/相等 | 天然干扰（数值接近），可复用转换锚点 |

每局 10 题、限时 8~10 秒、答错扣分、连对加成——全部复用现有引擎，只需要写生成器。
