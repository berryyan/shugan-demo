# 数学不再难 · 微信小程序（第一期：学习模块）

从网页版（https://berryyan.github.io/shugan-demo/）原生重写的微信小程序。
第一期范围：**首页题库列表 + 题库引导页 + 快问快答三模式（复习/闯关/进阶）+ 积分钱包**。
游戏厅、设置页（愿望激励/重置分数）、学习记录属第二期，本工程未包含。

## 工程结构

```
shugan-mp/
├── project.config.json   # 工程配置（appid 需换成你自己的）
├── app.json / app.js / app.wxss
├── core/
│   ├── logic.js          # 题库引擎（21 个题库，网页版 bank.ts 打包，出题/干扰项逻辑完全一致）
│   ├── scoring.js        # 计分规则（同网页版）
│   ├── wallet.js         # 积分钱包（本地存储）
│   ├── tokens.js         # 数学表达式 → 渲染 token（分数上下排版）
│   └── input.js          # 复习模式填空解析（整数/小数/分数/带分数）
└── pages/
    ├── home/             # 首页：年级/单元/题库 + 积分
    ├── intro/            # 引导页：考核点说明 + 三模式入口
    └── quiz/             # 快问快答引擎（三模式共用）
```

## 发布步骤

1. **安装微信开发者工具**（稳定版）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. **取 AppID**：登录 https://mp.weixin.qq.com → 设置 → 开发设置 → 复制 AppID，
   替换 `project.config.json` 里的 `"appid": "touristappid"`。
3. **导入工程**：开发者工具 → 导入项目 → 选择本目录 `shugan-mp`。
4. **预览**：工具栏「预览」生成二维码，微信扫码真机体验。
5. **上传**：工具栏「上传」，填版本号（如 0.1.0）。
6. **提审**：mp.weixin.qq.com → 版本管理 → 开发版本 → 提交审核。
   - 个人主体建议类目：**教育 > 教育辅助**（或「工具」），不要选需要办学资质的类目。
   - 服务内容均为本地随机出题，无后端、无用户信息收集，隐私协议选「不收集」。
7. 审核通过后点「发布」即上线。

## 与网页版的已知差异

- 无学习日志/记录页（第二期随设置页一起迁移）。
- 积分仅本机存储，无云端同步。

> 维护约定：今后所有功能与视觉调整，网页版与小程序版同步开发，两侧行为保持一致。

## 三模式规则（与网页版一致）

| 模式 | 题数 | 限时 | 作答方式 | 计分 |
|---|---|---|---|---|
| 复习 | 20 | 最长 | 填空（数字键盘，答对自动提交） | 低分，错答 +5s 重答（共 3 次机会） |
| 闯关 | 10 | 适中 | 选择（1 正确 + 3 干扰） | 基础分 + 速度 + 连对，错选扣分 +5s |
| 进阶 | 10 | 最短 | 选择 | 积分 ×2，**错一题或超时立即归零** |
