# 数感星球 · 题库原则总表与有理数缺口分析

> 2026-09-26 整理。依据：沪教版五四制（2024 版）六年级上册第 1 章「有理数」最新目录：
> 1.1 有理数的引入（正负数意义、数轴、相反数、绝对值）→ 1.2 加法与减法 → 1.3 乘法与除法 → 1.4 乘方 → 1.5 混合运算。
> 每个题库都是独立但可复用的"题库原则 + 干扰项原则"组合。

## 一、现有 10 个题库的原则总表

### 单元：有理数

**1. 小数 ⇄ 分数转换**（A1，基准限时 10s）
- 题库原则：四类均匀轮转（纯小数→分数 / 纯分数→小数 / 带整数小数→带分数 / 带分数→小数）；分母限 {2,4,5,8,10} 均匀抽取；分子在互质范围内随机（可约分的一律剔除）；带整数题整数部分 1~10 与 11~100 各占 50%
- 干扰项原则：未约分等价（数值对形式错）/ 分子分母颠倒 / 分子看错 / 分母看错 / 数位拼接（3/8→0.38）/ 小数点错位 / 漏整数部分 / 相等假分数（形式不符）；任何组合可用误区 ≥3

**2. 符号快闪**（C3，基准限时 5s，仅闯关/进阶，固定 3 选项）
- 题库原则：只判正负不计算；两项 80% + 三项代数和 20%；约 12% 恰为 0（互为相反数）；覆盖同号相加/异号相加/减负数结构；整数范围 ±19
- 干扰项原则：固定三选一（正数/负数/等于 0），干扰项即另外两个标签，提示语对应口诀（"符号跟绝对值大的走""减负数=加正数"）

**3. 正负数加减**（基准限时 12s，复习模式有负号键）
- 题库原则：两项 90% + 三项代数和 10%；整数 70% + 一位小数 30%；范围 ±20；加减各半，减法含"减去负数"
- 干扰项原则：符号看反 / 异号当同号（绝对值相加）/ 同号当异号（抵消）/ 减法方向反（b−a）/ 减没变加 / 邻值兜底（±1、±2…凑满 3 个）

### 单元：数感基础

**4. 分数改写**（A2，基准限时 10s）
- 题库原则：假分数→带分数 与 带分数→假分数 双向轮转；分母 {2,3,4,5,6,8}，整数部分 1~6，余数与分母互质
- 干扰项原则：商大 1 / 商小 1 / 余数看错 / 漏整数部分 / 颠倒成真分数 / 整数+分子直接相加

**5. 约分训练**（A3，基准限时 10s）
- 题库原则：先定最简分数（分母 3~9）再乘倍数 k∈{4,6,8,9,10,15,25}，保证 k 有真因子可造"没约干净"中间态；题面 ≤100
- 干扰项原则：没约干净（k 的每个真因子一种中间态）/ 只约分母 / 只约分子 / 分子分母减同数

**6. 大小比较**（B1，基准限时 8s，固定 3 选项，无复习模式）
- 题库原则：分数 vs 分数、小数 vs 分数混合；约 20% 等值变形题；非等值时差值 ≤0.3（逼数感而非硬算）；除不尽的分母（3）自动换等值分数形态
- 干扰项原则：固定三选一（左边大/右边大/一样大），干扰项 = 选成更小边 + 误判相等

### 单元：分数运算（全部：两项 90% + 三项连算 10%，答案最简、>1 写带分数）

**7. 分数加法**（12s）
- 题库原则：同分母 50% + 异分母 50%（异分母中 70% 倍数关系、30% 互质）；三项只出同分母连加
- 干扰项原则：分母也加（1/2+1/4=2/6）/ 通分忘乘分子 / 把加法算成乘法 / 分子加错 ±1 / 形态陷阱（未约分、假分数）

**8. 分数减法**（12s）
- 题库原则：同/异分母构成同加法；25% 为整数−分数（练借位）；保证结果为正；三项只出同分母连减（n1 > n2+n3）
- 干扰项原则：分子分母分别相减 / 通分忘乘分子 / 把减法算成加法 / 整数忘借位 / 抄错数 / 形态陷阱

**9. 分数乘法**（12s）
- 题库原则：真×真 / 整数×分数 / 带分数×分数 三形态均匀；三项连乘 10%
- 干扰项原则：误用倒数 / 只乘分子忘乘分母 / 整数加分子 / 整数乘分母 / 带分数整数忘乘 / 把乘法算成加法 / 形态陷阱

**10. 分数除法**（14s，内嵌 C4 倒数）
- 题库原则：真÷真 50% / 整数÷分数 25% / 带分数÷分数 25%；三项连除 10%（左结合）
- 干扰项原则：忘倒直接乘 / 倒错对象（倒了被除数）/ 漏带分数整数部分 / 商写倒 / 形态陷阱

### 通用兜底机制（所有运算题库）
- 形态陷阱两件套：可约分时出"未约分等价"、结果 >1 时出"假分数形式"（数值故意相等，考形式要求）
- 邻值兜底：误区候选去重后不足 3 个时，用"差一点点"邻值自动补齐，保证每题永远 1 正确 + 3 干扰
- 校验器：每题库 500 种子 × 10 题批量验证（乱码/结构/答案值/最简性/选项数），全绿才上线

## 三、建议优先级（待讨论）

1. **正负数比大小 + 相反数绝对值快闪**（1.1 缺口，最简单，复用现有引擎）
2. **正负数乘除 + 乘除符号快闪**（1.3 缺口，和加减结构对称）
3. **分数+小数混合运算**（1.5 缺口，P3 原定收尾项）
4. **乘方速记**（1.4 缺口，含 (-2)² vs -2² 经典陷阱）
5. 运算律巧算、运算顺序判断（偏"巧"不偏"速"，优先级可后放）
