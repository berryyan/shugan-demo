## 一、课标与教材边界（约束出题范围，不决定产品结构）

- 课标三学段：小数分数四则及混合运算**不超过三步**；会进行小数分数转化（不含循环小数）。
- 课标四学段（上海五四制六年级已涉及）：有理数加减乘除乘方及混合运算**以三步以内为主**，运用运算律简化运算。
- 沪教版五四制（2024 版，当前在用）：六年级上册第 1 章有理数（正负数→加减→乘除→乘方→混合运算）；分数四则运算在小学五年级已学，六年级不再单设章节——所以分数类题库定位为**小升初衔接的地基补强**，有理数类题库对齐六上进度。
- 结论："两项 90% + 三项 10%"的结构符合课标三步以内的边界。

## 二、组合运算题库出题规则草案（P2/P3 实施时执行）

> 这些是"原子能力的检验场"。每道组合题的干扰项都标注归因到原子能力（A1 转换 / C1 心算 / C2 通分 / C3 符号 / C4 倒数 / C5 顺序），为 P4 的错题归因报告积累数据。

### 正负数加减（P3）
- 两项：(-3)+5、4-(-6) 等；|a|,|b| ≤ 20 起步，自适应可升到 100
- 三项 10%：(-3)+7-5 等，不超过三步
- 干扰项归因：C3 符号看错（(-3)+5 → -8）、C3 减负数当加正数、C1 心算错

### 分数加法 / 减法（P2）
- 同分母 50% + 异分母 50%；分母围绕 2、3、4、5、6、8、10、12；答案最简
- 干扰项归因：C2 未通分直接加（1/2+1/3 → 2/5）、A3 未约分、C1 心算错

### 分数乘法 / 除法（P2）
- 真分数×真分数、整数×分数、分数÷分数、整数÷分数
- 干扰项归因：C4 除法忘倒过来、A3 未约分、分子分母交叉乘错

### 分数 + 小数混合运算（P3）
- 两项 90%：0.5+¼、1.2×⅔、¾÷0.25；三项 10%：0.5+¼-0.25
- 答案以最简分数或有限小数给出
- 干扰项归因：A1 转换错（0.5 当 1/5）、C5 运算顺序错（三项题）、C4 倒数错
